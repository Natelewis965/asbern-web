Honest gaps

Things other bots have that Asbern does not.

If one of these is the reason you are shopping, Asbern is not your answer today, and we would rather you found that out on this page than after paying. Nothing here has code behind it beyond what the note says.

Features that are not built
FeatureStatus
Deliberately out of scope. Collectible/gacha mechanics, YouTube-sourced music (the two biggest music bots were shut down over exactly that, and the risk gets worse once real money is in the same product), cross-server alt detection, and an unbounded general-purpose chatbot. These are decisions, not gaps.
What is coming next. The highest-priority missing feature is importing levels from MEE6 and Arcane, because it removes the “we would lose our levels” objection outright. After that: the web dashboard, generated from the same 221-control registry the Discord console already renders.
Cloud or your own hardware

Where each piece runs.

Which components run where
ComponentSelf-hostedCloud
Self-hosting is not finished. The agent pattern runs in production today, but it currently dials inward across a local network. The outbound bridge, the pairing flow and the signed installer are on the roadmap and are not shipped. Until they are, self-hosting means Docker Compose and a willingness to read logs.
